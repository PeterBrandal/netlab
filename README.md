# Netlab

A project for understanding networking from the wire up.

This repo exists so I can challenge myself and stop reaching for AI every time I
hit a problem. The rule is simple: I do the thinking and I write the code. By the
end I want a deep, working understanding of the protocols the Internet actually
runs on — not a reading knowledge of them.

## Goals

- Become fluent in the Linux terminal and the commands that matter.
- Learn React properly, writing it by hand, with no scaffolding I don't understand.
- Understand networking from the application layer down to the physical layer.
- Build an interactive web application — real terminals plus UI components — that
  visualizes the Internet protocols well enough to hand to NTNU as a genuine
  teaching tool.
